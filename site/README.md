# tuika.dev

The Nimbus-based website for [tuika](https://github.com/everruns/tuika).
Guide pages are generated from the repository's top-level `docs/` directory;
there is no second copy to maintain.

```sh
pnpm install
pnpm dev
```

See `AGENT.md` for the content contract, validation commands, and Cloudflare
deployment notes.
